# Medical Diagnosis Assistant 🩺

AI-powered medical diagnosis system using Bayesian inference, built from scratch in Python.

## Features
- Diagnoses 60+ diseases across 12 medical categories
- Patient profiling (age & biological sex)
- Clinical prior probability modeling
- Real-time emergency detection
- Interactive Streamlit UI

## How to run locally
pip install -r requirements.txt
streamlit run app.py
